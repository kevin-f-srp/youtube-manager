# 持续在线的剪辑 Agent · Web Demo

工作台把素材库、原片与成片预览、按画面交流、剪辑执行和导出放在同一页面。每个项目关联一个持续使用的 DSH（DeepSeek Harness）会话；后续消息恢复同一会话，不再每次要求模型生成整份剪辑 JSON。

这是 macOS 本地单用户 Demo，暂不制作独立桌面应用。服务监听本机回环地址，不是公网多用户服务。浏览器不需要另开 Codex 或 Claude Code 会话。

## 启动

需要 Python 3.12 或更高、macOS Apple Silicon、FFmpeg，以及与项目兼容的剪辑引擎环境。

```bash
python3 -m venv .venv-studio
.venv-studio/bin/python -m pip install -r requirements-studio.txt
.venv-studio/bin/python -m src.studio.app \
  --data sessions/video-studio \
  --engine-python /absolute/path/to/youtube-manager/venv/bin/python
```

打开 http://127.0.0.1:8770/ 。默认数据路径是 `~/.local/share/video-studio`；一个数据目录仅允许一个服务进程。`--engine-root` 可指定另一个兼容引擎目录。

在连接配置填写 GPT 或 Claude 的模型名、API 密钥和可选代理接口地址。地址按服务保存在当前浏览器；密钥只在服务内存中，重启后需重新配置，也可通过环境变量 `OPENAI_API_KEY` / `ANTHROPIC_API_KEY` 提供。模型名称必须由实际接口支持，Codex/Claude Code 订阅登录不会自动转换为 API 认证。OpenAI 兼容地址通常包含 `/v1`；Anthropic 适配器会自行追加 `/v1/messages`。

## 使用

1. 导入照片和视频所在目录，或已有 `01 - Unedited` / `02 - Export/edit/edl.json` 的工程。目录直接子文件会加入素材清单；整理素材会生成缩略图及视频抽帧。
2. 点击素材查看原片，下方显示当前剪辑方案采用的区间；点击区间可以跳转。
3. 直接输入消息并发送。默认携带发送瞬间的画面和时间，播放不会因此暂停。取消“发送时附带当前画面”可讨论整个项目。
4. Agent 会回答咨询问题；对于明确要求的修改，会调用工具操作工作台副本并检查结果，无需再点击“应用建议”。旧任务仍保留原有建议应用流程。
5. 页面展示执行状态、工具调用、生成素材的查看链接及预览下载/播放入口。执行中可以继续发消息，新消息排队，上一项任务结束后继续处理。
6. 可继续说“再小一点”“恢复刚才的版本”。Agent 使用原会话历史和当前工程继续；历史剪辑方案可通过工具恢复。生成素材各自保留，不覆盖旧版。
7. 需要完整效果时要求生成预览；确认后用导出 4K。复用原渲染器的声音检查、完整解码和尺寸检查。

首次建立持续会话会带入最近的旧审阅消息，同时告知模型旧建议不代表已应用。更换模型或接口地址时，在连接配置中“新建对话”，旧会话与工程仍保留。

## 已接入的实际操作

- 查看当前工程、素材信息、工程文本和剪辑引擎源码。
- 查看任意已注册素材的指定时间画面，图片实际返回模型。
- 修改镜头入出点、开关、速度、画幅、缩放、字幕和说明；仍进行字段校验和版本检查。
- 查找路线图配置和对应镜头，列出本机字体，修改字体与字号等样式。
- 调用已有 `src.editor.routemap` 生成地图静帧/视频；检查解码后更新指定地图镜头，原工程保持不变。
- 生成整个项目的预览并复用原有导出检查。
- 列出和恢复历史剪辑方案。

模型可以读取项目范围内的文本，并调用这些真实工具；本版没有开放任意终端命令或任意文件写入。尚未接入配音生成、语音转写、音乐编辑、封面设计、平台发布和图形化多轨时间线。后续按实际任务补充工具，不把未接入的操作描述为已经可以执行。

## 运行与恢复

网页服务持续接收消息；DSH 运行环境按任务启动，并从项目持久会话恢复历史，空闲时不持续请求模型。会话记录保存在 `agent/`，工程在 `edl.json`，历史在 `history/`，生成素材在 `generated/`，各次请求及执行记录在 `jobs/`。

同一项目的任务串行执行，运行时不允许页面手动覆盖工程。取消先请求正常关闭 SDK 运行环境、保存会话，再清理残留工具进程；取消不会撤销已经完成的修改。服务重启后未完成任务标记为中断，可重试，但不自动续算中断的渲染。

原始照片视频、原工程和地图配置只读。辅助媒体继续引用原项目，因此不要移动或删除原项目。恢复剪辑方案后，需重新生成预览才会更新可见视频。生成地图的视频和配置是独立版本，恢复旧工程仍可找到对应文件。

发送给所选模型服务的内容包括用户消息、工程信息、选取的图片及工具返回内容。首次最多 384 份素材拼成 16 张图；后续默认依靠已有会话和按需取帧，避免每轮重复发送整个素材库。视频抽帧不等于完整观看或听音。

## 代码与验证

- `app.py`：网页接口、串行任务队列、取消、会话状态和产物访问。
- `harness.py`：固定 SDK 版本、GPT/Claude 路由、会话创建和恢复、错误分类。
- `agent_tools.mjs`：DSH 插件，注册模型可调用的剪辑工具，将图片结果存入 DSH 附件。
- `agent_tools.py`：项目范围内的实际读写、地图渲染、预览及历史恢复。
- `worker.py`：素材整理、发送画面和工程上下文、执行事件、视频渲染检查。
- `store.py` / `context.py`：工程版本、校验以及原片/成片时间定位。

```bash
python -m unittest discover -s tests -p 'test_studio.py' -v
# 真实 DSH + 本机模拟模型，无需付费模型密钥
STUDIO_HARNESS_TESTS=1 python -m unittest discover -s tests -p 'test_studio_harness.py' -v
```

本机验证覆盖 GPT/Claude 实际工具执行、图片回传、跨进程会话恢复、取消后恢复、浏览器连续发送和排队。独立测试工程连续修改两次地图字号，完成地图视频和 1920×1080 成片预览、音频/解码检查与历史恢复，原工程未变。真实模型对自然语言的理解与剪辑质量仍需使用实际模型服务验收。
