# 本地视频工作台原型

工作台将素材浏览、镜头与字幕编辑、AI 剪辑建议、预览和 4K 导出放在同一个页面中。GPT 和 Claude 通过 DeepSeek Harness Python SDK 接入；浏览器不需要另开 Codex 或 Claude Code 会话。

这是 macOS 本地单用户原型。视频编码复用现有渲染器的 VideoToolbox 硬件编码；本版没有验证 Windows/Linux 视频导出。Flask 开发服务器只绑定回环地址，不能作为公网多用户服务部署。

## 安装与启动

需要 Python 3.10 及以上、macOS 14 及以上 Apple Silicon、FFmpeg。推荐 Python 3.12 或更高。

```bash
python3 -m venv .venv-studio
.venv-studio/bin/python -m pip install -r requirements-studio.txt
.venv-studio/bin/python -m src.studio.app
```

打开 http://127.0.0.1:8770/ 。默认数据位于 `~/.local/share/video-studio`，可用 `--data` 指定。一个数据目录同时只允许一个服务进程。

页面中选择 OpenAI（GPT）或 Anthropic（Claude），填写账号可用的模型 ID，在“连接配置”输入 API 密钥。密钥只保存在服务内存中，服务退出后消失。也可以在启动服务之前设置 `OPENAI_API_KEY` 或 `ANTHROPIC_API_KEY`。不要将密钥写入工程、日志或提交到仓库。当前 Codex/Claude Code 登录状态不会自动转成 API 认证。

自定义地址是提供方 API 的根地址：OpenAI 兼容服务通常包含 `/v1`；Anthropic 适配器会追加 `/v1/messages`，不要重复附加 `/v1`。留空使用官方地址。模型可用性、额度和图片支持由实际账号与服务决定。

复用另一个本地剪辑引擎及其虚拟环境：

```bash
.venv-studio/bin/python -m src.studio.app \
  --engine-root /absolute/path/to/youtube-manager \
  --engine-python /absolute/path/to/youtube-manager/venv/bin/python
```

`--engine-python` 保留虚拟环境入口，不会解引用为系统 Python。界面服务与引擎环境可以独立升级。导入扩展工程时，应指定创建该工程的兼容引擎；跨版本高级效果不保证兼容。

## 页面流程

1. 导入一个包含照片、视频的本机目录，或已有 `01 - Unedited` / `02 - Export/edit/edl.json` 的项目。当前扫描目录直接子文件，不递归扫描。
2. 素材整理会校正照片方向、读取视频信息并生成视频抽帧图。存在拍摄时间时按时间排列，否则按文件名排列。视频是稀疏抽帧，不能作为完整观看或听音的证明。
3. 点击素材上的加号可以手动建立镜头；点击镜头可编辑原素材入点、出点、速度、画幅和字幕。字幕编辑目前使用 JSON 文本。
4. 选择素材和镜头，在剪辑助手输入要求。未选择素材时使用全部素材，单次最多 384 份；图片按 12 份一组拼接。发送前保存未保存的工程。请求会把工程、素材信息和缩略图传给选择的模型服务，不上传原始视频文件。
5. 模型返回完整镜头列表与修改说明。服务校验字段、素材引用和工程版本；点击“应用建议”才更新工作台工程。若提交请求后手动改过工程，旧建议会被拒绝，避免覆盖新修改。
6. 生成预览；审阅后继续提出要求。每次请求携带当前工程、选中镜头和播放位置。当前模型调用是独立任务，不自动继承此前所有聊天记录；此前建议及说明仍在页面和任务文件中保留。
7. 导出 4K。任务依次完成渲染、完整音视频解码和输出信息检查；成功后提供下载入口。每次输出使用独立任务目录，旧成片不覆盖。

原始素材只被读取，原工程不写回。工作台维护自己的 `edl.json`，导出任务另存工程快照。辅助音乐、旁白等仍引用原项目文件，因此不要移动或删除原项目。

## 工程与任务

- `src/studio/app.py`：本地 HTTP 接口、任务子进程、同源与请求令牌检查。
- `src/studio/store.py`：项目副本、字段校验、版本冲突和历史工程。
- `src/studio/harness.py`：固定 `deepseek-harness-sdk==0.2.1rc2`，配置多模型适配器，禁用模型侧 shell、文件操作和附加会话日志上传插件。图片通过 SDK 的 `mimeType` 字段传入。
- `src/studio/worker.py`：素材整理、模型建议、引擎适配和导出检查。
- `src/studio/static/`：无需前端构建的工作台页面。

任务有运行、完成、失败、取消、中断状态。取消会终止进程组；未终止的旧进程不会放行新的同项目任务。服务重启后未完成任务标记为中断，用户需重试，本版不宣称断点续算。任务失败不会应用模型建议，也不会把未完成视频暴露为成功输出。

上游渲染器未包含本地照片扩展时，工作台先按完整画幅或裁剪规则生成照片片段，再调用原渲染器。照片细致移动、复杂画中画等高级效果应使用匹配的引擎；不要把本原型视为跨版本工程迁移工具。

## 验证

```bash
python -m unittest discover -s tests -p 'test_studio.py' -v
# 可选：真实 Harness + 本机模拟 OpenAI/Anthropic 接口，无需真实密钥
STUDIO_HARNESS_TESTS=1 python -m unittest discover -s tests -p 'test_studio_harness.py' -v
```

已实际验证浏览器导入、镜头编辑和保存；合成照片与带声音测试视频组成的 4 秒短片成功生成 1920×1080 预览和 3840×2160 成片，完整解码通过。Harness 的 GPT/Claude 文字及图片请求使用真实运行时和本机模拟响应验证，未使用真实提供方密钥，因此真实模型的剪辑质量、额度和在线连接仍需用户配置后验收。

## 当前边界

本版实现“素材 → 建议 → 应用 → 预览 → 修改 → 导出”。尚未提供配音生成/音色选择、自动语音转写入口、音乐编辑、封面设计、平台发布、图形化多轨时间线或自动恢复中断渲染。已有工程的声音配置随工程保留，AI 建议仅能改受支持的镜头字段。模型对视频的理解基于抽帧，没有提供原声，因此不会自动生成可信的现场对白字幕。

### 按画面交流与原片选段

点击素材缩略图后，播放器下方显示当前剪辑方案选用的区间，可点击跳转；关闭的镜头和跳过的区间不计入。
发送消息时默认自动读取播放器当时的画面和时间，播放中不暂停；原片与成片会分别标明。无需先点按钮。取消“发送时附带当前画面”可发送整个项目范围的要求。画面尚未加载或正在跳转时会提示等待，避免附错画面。“暂停并查看交流画面”仅用于提前查看，真正发送时仍以播放器当时的位置为准。
成片定位使用生成该成片时的剪辑方案，支持跳过区间与倍速换算。导入的旧预览没有可靠的剪辑快照时，只提供实际画面和成片时间，不猜测镜头编号。模型仍通过“生成剪辑建议”返回建议，尚非独立的自由问答模式。
